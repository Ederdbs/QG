From the Marker Matrix to Diversity Metrics

Maize hybrid selection under a genetic diversity constraint

Author

Technical document

Published

Scope

This document describes, with explicit algebra and the code that implements it, the path from the lines’ marker matrix to the metrics used to constrain diversity loss when selecting hybrids.

The central thesis is that two different matrices are needed, and swapping them is the easiest mistake to make: the genomic matrix of VanRaden (2008) to predict performance, and the molecular coancestry matrix of Caballero and Toro (2002) to measure diversity. Section @ref(why-not-g) shows algebraically and numerically why the first one cannot serve the second.

As a running example, a small simulated set:

cfg <- modifyList(sim_config, list(n_pool_A = 25, n_pool_B = 25, m = 1500))
ctx <- simulate_data(cfg)
n_sel <- 40
c(hybrids = ctx$N, markers = ctx$m, lines = ctx$n_lines)
#> hybrids markers   lines 
#>     625    1500      50

From Line to Hybrid

Coding

Let \(\mathbf{M}^{L}\) be the \(L \times m\) matrix of line genotypes, with \(M^{L}_{ik} \in \{0, 2\}\) = count of the reference allele at marker \(k\). Inbred lines are homozygous, so the value 1 never occurs — residual heterozygotes must be imputed or discarded beforehand.

Hybrid Genotype

The \(F_1\) hybrid between lines \(a\) and \(b\) receives one gamete from each parent. Since both parents are homozygous, the gamete from \(a\) carries \(M^{L}_{ak}/2\) copies of the reference allele, and therefore

\[ M^{H}_{(ab)k} \;=\; \frac{M^{L}_{ak} + M^{L}_{bk}}{2} \;\in\; \{0, 1, 2\}. \]

The value 1 appears exactly at markers where the two lines differ — these are the hybrid’s heterozygous loci, and they are the ones carrying heterosis. Predicting the hybrid’s genotype is deterministic, not statistical: it is the one piece of information that requires no assumption at all (Technow et al. 2014).

# R/00_data.R
ped <- expand.grid(a = a_ids, b = b_ids)                    # all A x B combinations
M   <- (L[ped$a, , drop = FALSE] + L[ped$b, , drop = FALSE]) / 2

From here on we work with the within-individual reference-allele frequency, which is the natural quantity for coancestry:

\[ x_{ik} \;=\; \frac{M^{H}_{ik}}{2} \;\in\; \{0,\; 0.5,\; 1\}. \]

str(ctx$X[1:3, 1:6])
#>  num [1:3, 1:6] 0 0 0.5 0.5 0 0 0.5 0.5 0.5 1 ...

The VanRaden Genomic Matrix

Definition

With \(p_k\) = reference-allele frequency in the hybrid population, \(\mathbf{Z} = \mathbf{M}^{H} - \mathbf{1}\,2\mathbf{p}'\) is the centered matrix and

\[ \mathbf{G} \;=\; \frac{\mathbf{Z}\mathbf{Z}'}{2\sum_{k} p_k (1-p_k)}. \]

This is VanRaden (2008)’s first parametrization. It estimates realized additive relationship and is what feeds GBLUP to predict traits from already-estimated marker effects.

vanraden_G <- function(M) {
  p <- colMeans(M) / 2
  Z <- sweep(M, 2, 2 * p, "-")
  list(G = tcrossprod(Z) / (2 * sum(p * (1 - p))), Z = Z, p = p)
}

Why G Cannot Measure Diversity

Centering on \(2\mathbf{p}\) uses frequencies from the population itself. So every column of \(\mathbf{Z}\) sums to zero:

\[ \mathbf{Z}'\mathbf{1} = \mathbf{0} \quad\Longrightarrow\quad \mathbf{1}'\mathbf{G}\mathbf{1} \;=\; \frac{\mathbf{1}'\mathbf{Z}\mathbf{Z}'\mathbf{1}}{2\sum_k p_k q_k} \;=\; \frac{\lVert \mathbf{Z}'\mathbf{1}\rVert^2}{2\sum_k p_k q_k} \;=\; 0 . \]

The sum of all elements of \(\mathbf{G}\) is identically zero. Since group coancestry is proportional to that sum, it equals zero for the whole population, and the status number \(N_s = 1/(2\theta)\) diverges:

c(sum_G       = sum(ctx$G),
  theta_on_G  = mean(ctx$G) / 2,
  Ns_on_G     = 1 / (2 * mean(ctx$G) / 2))
#>        sum_G   theta_on_G      Ns_on_G 
#> -4.39605e-11 -5.68063e-17 -8.80184e+15

In subsets the sum isn’t zero, but it is a centered quantity that oscillates around zero and takes negative values. It is not a probability and admits no identity-by-descent interpretation.

The root of the problem is the implicit base population. \(\mathbf{G}\) measures relatedness relative to the current population; diversity requires an absolute scale. See Gómez-Romano et al. (2016) and Meuwissen et al. (2020) for a discussion of which genomic coancestry matrix to use in which context.

f Is Not an Ad Hoc Choice — It Has a Name in the GOC Literature

Two independent lines of work converge on the matrix used here. Nejati-Javaremi et al. (1997) proposed the allelic-similarity method, \(f_{ij} = 0.25\sum_{k=1}^{2}\sum_{l=1}^{2}\delta_{kl}\) where \(\delta_{kl}=1\) if the \(k\)-th allele of \(i\) equals the \(l\)-th allele of \(j\) — exactly the identity-by-state average used in \(\mathbf{f}\) above, generalized here from single loci to a genome-wide mean. Gómez-Romano et al. (2016) contrast it directly against the crossproduct-based matrices (VanRaden-style): the allelic-similarity matrix is guaranteed to stay in \([0,1]\) by construction, while crossproduct matrices normalized by current allele frequencies are not — precisely the failure mode demonstrated numerically above.

The same matrix reappears from a second angle. Toro et al. (2014) and Meuwissen et al. (2020) show that fixing the VanRaden centering frequency at \(p_k = 0.5\) for every marker — instead of the sample frequency \(\bar p_k\) — produces a matrix, denoted \(\mathbf{G}_{0.5}\), that “is proportional to homozygosity-based inbreeding and molecular coancestry.” That is structurally our \(\mathbf{f}\): replacing \(2p_k\) with \(1\) in the VanRaden centering removes the population-dependent term that forced \(\mathbf{1}'\mathbf{G}\mathbf{1}=0\), which is exactly the fix derived independently in Section @ref(f-molecular) from first principles. \(\mathbf{f}\) is not a heuristic substitute for \(\mathbf{G}\) — it is the member of the VanRaden family that has an absolute scale, arrived at from two unrelated derivations in the quantitative-genetics literature.

The Molecular Coancestry Matrix

Definition

Malécot’s coancestry (Malécot 1948) between \(i\) and \(j\) is the probability that two randomly sampled alleles, one from each individual, at the same locus, are identical. Replacing identity by descent with identity by state — what markers actually observe — yields molecular coancestry (Caballero and Toro 2002, 2000):

\[ f_{ij} \;=\; \frac{1}{m}\sum_{k=1}^{m} \Big[\, x_{ik}\,x_{jk} \;+\; (1-x_{ik})(1-x_{jk}) \,\Big]. \]

The first term is the probability that both sampled alleles are the reference allele; the second, that both are the alternative allele. Properties:

  • \(f_{ij} \in [0, 1]\) always. A negative value is a symptom of the wrong matrix being used.
  • Self-coancestry is \(f_{ii} = (1 + F_i)/2\), with \(F_i\) the individual’s molecular homozygosity (Wright 1922). For a fully heterozygous \(F_1\), \(f_{ii} = 0.5\).
  • No centering, no scaling, no arbitrary base population.

Computable Form

Computing the double sum naively is \(O(n^2 m)\). Expanding:

\[ \sum_k \big[x_{ik}x_{jk} + (1-x_{ik})(1-x_{jk})\big] = 2\sum_k x_{ik}x_{jk} \;-\; \sum_k x_{ik} \;-\; \sum_k x_{jk} \;+\; m, \]

which gives, with \(\mathbf{s} = \mathbf{X}\mathbf{1}\) (row sums),

\[ \boxed{\;\mathbf{f} \;=\; \frac{1}{m}\Big( 2\,\mathbf{X}\mathbf{X}' \;-\; \mathbf{s}\mathbf{1}' \;-\; \mathbf{1}\mathbf{s}' \;+\; m\,\mathbf{J} \Big)\;} \]

with \(\mathbf{J}\) the all-ones matrix. A single matrix product, the same cost as a \(\mathbf{G}\) matrix.

molecular_coancestry <- function(X) {
  m <- ncol(X)
  s <- rowSums(X)
  (2 * tcrossprod(X) - outer(s, rep(1, nrow(X))) -
     outer(rep(1, nrow(X)), s) + m) / m
}
c(minimum = min(ctx$f), maximum = max(ctx$f),
  diagonal_mean = mean(diag(ctx$f)), off_diagonal_mean = mean(ctx$f[upper.tri(ctx$f)]))
#>           minimum           maximum     diagonal_mean off_diagonal_mean 
#>          0.631667          0.835667          0.816308          0.668651

The value 0.5 would be the floor of the diagonal, reached by a hybrid heterozygous at every marker. The excess above 0.5 measures exactly the fraction of markers at which the two parent lines carry the same allele — loci where the \(F_1\) is homozygous and, by definition, contribute nothing to heterosis:

fd <- mean(diag(ctx$f))
c(diagonal_mean = fd,
  molecular_F = 2 * fd - 1,             # f_ii = (1 + F_i)/2
  heterozygous_fraction = 2 * (1 - fd))
#>         diagonal_mean           molecular_F heterozygous_fraction 
#>              0.816308              0.632617              0.367383

This fraction depends directly on the divergence between heterotic pools (fst in sim_config): more divergent pools produce more heterozygous \(F_1\) hybrids and a diagonal closer to 0.5.

Metrics Derived from f

Group Coancestry and the Off-Diagonal Metric Problem

The group coancestry (Cockerham 1967) of a set \(S\) of \(n\) individuals is the mean of all \(n^2\) elements, diagonal included:

\[ \theta_S \;=\; \frac{1}{n^2}\sum_{i \in S}\sum_{j \in S} f_{ij} \;=\; \frac{1}{n^2}\,\mathbf{1}'\mathbf{f}_S\mathbf{1}. \]

It is the probability that two alleles sampled at random from the whole set are identical — including the possibility of both coming from the same individual. That is why the diagonal enters: it represents the chance of sampling the same individual twice, which is real when the set is used as a crossing pool.

Splitting diagonal (\(\bar f_d\)) from off-diagonal (\(\bar f_o\)):

\[ \theta_S \;=\; \frac{\bar f_d}{n} \;+\; \frac{n-1}{n}\,\bar f_o . \tag{1} \]

The off-diagonal mean \(\bar f_o\) is therefore just one of the two terms. When \(\bar f_d\) varies little across individuals — the case of an all-\(F_1\) population — the two metrics rank almost identically, and the off-diagonal metric works fine as a ranking. What it does not provide is the interpretable scale and the correct baseline (Sections @ref(ns) and @ref(baseline)).

idx <- sample.int(ctx$N, n_sel)
theta_group(idx, ctx)
#> [1] 0.673137

Gene Diversity: θ and He Are the Same Quantity

This is the result that simplifies everything else. Starting from the definition and swapping the order of summation:

\[ \theta_S \;=\; \frac{1}{m}\sum_k \left[ \frac{1}{n^2}\sum_i\sum_j x_{ik}x_{jk} + \frac{1}{n^2}\sum_i\sum_j (1-x_{ik})(1-x_{jk}) \right] \]

The double sum factors: \(\frac{1}{n^2}\sum_i\sum_j x_{ik}x_{jk} = \big(\frac{1}{n}\sum_i x_{ik}\big)^2 = \bar p_k^2\), where \(\bar p_k\) is the group’s allele frequency. Hence

\[ \theta_S \;=\; \frac{1}{m}\sum_k \big(\bar p_k^2 + \bar q_k^2\big), \qquad\text{and therefore}\qquad \boxed{\;GD_S \;=\; 1 - \theta_S \;=\; \frac{1}{m}\sum_k 2\,\bar p_k \bar q_k \;\equiv\; H_e\;} \]

which is exactly Nei’s gene diversity (Nei 1973). Group coancestry and expected heterozygosity are not independent checks: they are the same quantity written two ways.

Three practical consequences:

  1. One fewer metric to justify to the technical committee.
  2. “Losing 5% of diversity” gains an exact meaning: 5% of the set’s expected heterozygosity.
  3. Two computation routes with the same result and very different costs — the matrix route is \(O(n^2)\), the frequency route is \(O(nm)\). For \(n=200\) and \(m=25000\) that is 40 thousand versus 5 million operations. The matrix route is ~100x cheaper, and it’s the one that belongs in the optimizer’s inner loop.
c(via_submatrix  = theta_group(idx, ctx),
  via_frequency   = theta_from_freq(idx, ctx),
  difference      = theta_group(idx, ctx) - theta_from_freq(idx, ctx))
#> via_submatrix via_frequency    difference 
#>      0.673137      0.673137      0.000000
c(GD = gene_diversity(idx, ctx), He_Nei = he_nei(idx, ctx))
#>       GD   He_Nei 
#> 0.326863 0.326863

Equality to machine precision is the implementation’s strongest sanity check: if it fails, matrix f is centered, rescaled, or has the wrong coding.

Status Number Ns

Lindgren et al. (1997) and Lindgren and Mullin (1998) propose expressing group coancestry on the scale of individual counts:

\[ N_s \;=\; \frac{1}{2\,\theta_S}. \]

The reading is direct: \(N_s\) is the number of unrelated, non-inbred individuals that would have the same gene diversity as the observed set. Edge cases:

fake <- ctx
fake$f <- matrix(0.5, 5, 5)      # unrelated, p = 0.5
c(theta = theta_group(1:5, fake), Ns = status_number(1:5, fake))
#> theta    Ns 
#>   0.5   1.0
fake$f <- matrix(1, 5, 5)        # all identical and homozygous
c(theta = theta_group(1:5, fake), Ns = status_number(1:5, fake))
#> theta    Ns 
#>   1.0   0.5

An Important Caveat About Ne

Toro et al. (2020) show that the rate-based effective size, \(N_e = 1/(2\Delta F)\), loses meaning under molecular diversity management: optimization increases diversity in early generations, producing a negative \(\Delta F\) and therefore a negative \(N_e\), and its long-term behavior fails to converge to an asymptotic value.

This does not invalidate \(N_s\). The distinction is that \(N_s\) is a monotonic reparametrization of \(\theta\) — a static descriptor of the set — while \(N_e\) is a rate between generations. Use \(N_s\) to compare sets; don’t extrapolate it to project future drift.

For the same reason, do not use the linkage-disequilibrium-based \(N_e\) here (\(N_e = 1/(3(\bar r^2 - 1/S))\)): it estimates population history, not the composition of a selected sample.

A Second Caveat: θ Tracks Homozygosity, Not Drift

Meuwissen et al. (2020) draw a distinction that classical theory collapses but genomic management reopens: homozygosity-based inbreeding (\(F_{\text{hom}}\), what \(\theta\) and \(GD\) measure here) and drift-based inbreeding (\(F_{\text{drift}}\), the squared change in allele frequency relative to a base population) are the same quantity only under neutral, unlinked loci and random mating. Once selection actively manages \(\mathbf{f}\)-type (homozygosity) matrices, the two diverge substantially — sometimes with opposite sign.

The mechanism is the same one identified in the previous caveat: minimizing \(\theta_S\) pushes allele frequencies toward 0.5, since \(\theta_S = \frac{1}{m}\sum_k(\bar p_k^2 + \bar q_k^2)\) is minimized at \(\bar p_k = 0.5\). This lowers \(F_{\text{hom}}\) efficiently — sometimes past the point of actually reducing drift, because alleles starting below 0.5 are pushed up and alleles above 0.5 are pushed down, which is not the same direction random drift would take them. Meuwissen et al. (2020) report scenarios where optimizing a homozygosity-based matrix produced higher drift-based inbreeding than doing nothing, while the reverse (optimizing IBD-based matrices) kept both aligned.

Practical reading for this pipeline: \(GD\) and \(N_s\) answer “how much heterozygosity does the selection preserve,” which is the right question for next season’s hybrid vigor. They do not certify that allele frequencies are moving in the direction unmanaged drift would have taken them, which matters more for multi-generation recurrent selection than for a single round of hybrid selection. If this pipeline is later extended to plan several breeding cycles, allelic richness (Section @ref(richness-section), which counts alleles lost rather than frequencies pulled toward 0.5) and pedigree- or haplotype-based relationship measures become the safer long-run compasses.

Effective Number of Parents

A metric independent of \(\mathbf{f}\), computed purely from the hybrids’ pedigree. Letting \(p_i\) be the frequency with which line \(i\) appears as a parent among the selected hybrids,

\[ N_{e(\text{par})} \;=\; \frac{1}{\sum_i p_i^2}, \]

the inverse Simpson index. It captures precisely what coancestry blurs: 200 hybrids can have acceptable \(\theta\) while still drawing on only 12 lines, if those 12 happen to be genetically distant from one another.

c(random          = ne_parents(sel_random(ctx, n_sel), ctx),
  truncation      = ne_parents(sel_truncation(ctx, n_sel), ctx),
  theoretical_max = ctx$n_lines)
#>          random      truncation theoretical_max 
#>         35.5556         12.4031         50.0000

Its cost is negligible (a tabulate count), which makes it a natural candidate to enter the objective function alongside \(\theta\).

Allelic Richness

\(\theta\) and \(H_e\) are averages across markers and are dominated by intermediate-frequency alleles. A lost rare allele barely moves them, yet the loss is irreversible. We count markers that were polymorphic in the population and became rare or fixed in the selection:

\[ A_{\text{lost}} \;=\; \#\{k : \text{MAF}_k^{(S)} < 0.05 \;\wedge\; \text{MAF}_k^{(\text{pop})} \ge 0.05 \}. \]

c(random      = alleles_lost(sel_random(ctx, n_sel), ctx),
  truncation  = alleles_lost(sel_truncation(ctx, n_sel), ctx))
#>     random truncation 
#>         12         79

It is the only metric in the set genuinely non-redundant with \(\theta\), and the two-pronged caveat above explains why that independence matters. López-Cortegano et al. (2019) compared, in a subdivided simulated population, management strategies that maximize expected heterozygosity (\(H_T\), the same family as our \(GD\)) against strategies that maximize allelic diversity (\(A_T\), closer to this section’s allele count). Their finding: maximizing \(A_T\) retained a larger number of alleles and produced better control of molecular inbreeding (\(F\)) than maximizing \(H_T\) — heterozygosity-maximizing management pushes allele frequencies toward 0.5, which favors rare alleles in the short run but does not stop them drifting to loss once they are no longer the rarest ones, whereas allele-count management defends every segregating allele directly. Their recommendation for conservation programs of structured populations was to make \(A_T\), not \(H_T\), the primary target. In this pipeline’s terms: alleles_lost deserves a place next to \(\theta\) as a tracked outcome, not only as a post-hoc sanity check, whenever the selection will feed multiple future cycles rather than a single hybrid release.

Distances: E-NE and A-NE

With distance \(d_{ij} = 1 - f_{ij}\), De Beukelaer et al. (2018) define in Core Hunter 3 two measures that capture opposite aspects that \(\theta\) alone cannot separate:

\[ \text{E-NE} = \frac{1}{n}\sum_{i \in S} \min_{j \in S,\, j \ne i} d_{ij}, \qquad \text{A-NE} = \frac{1}{N}\sum_{i=1}^{N} \min_{j \in S} d_{ij}. \]

  • E-NE (entry-to-nearest-entry) measures non-redundancy within the selection. It tells apart “200 individuals spread out” from “100 near-identical pairs spread out”, configurations that can share the same \(\theta\).
  • A-NE (accession-to-nearest-entry) measures representativeness of the population. It detects a selection that optimizes \(\theta\) by concentrating in one region of genetic space while ignoring the rest.
sapply(list(random = sel_random(ctx, n_sel),
            truncation = sel_truncation(ctx, n_sel),
            greedy_div = sel_greedy(ctx, n_sel, w = 0)),
       function(s) c(ENE = ene(s, ctx), ANE = ane(s, ctx)))
#>       random truncation greedy_div
#> ENE 0.258300   0.255242   0.268167
#> ANE 0.254442   0.276140   0.261401

Effective Dimensionality

Over the eigenvalues \(\lambda_1 \ge \dots \ge \lambda_n\) of the submatrix \(\mathbf{f}_S\), the participation ratio

\[ D_{\text{eff}} \;=\; \frac{\left(\sum_i \lambda_i\right)^2}{\sum_i \lambda_i^2} \]

counts how many independent directions of genetic variation remain. It equals 1 if all variation lies on a single axis and \(n\) if it is spread evenly.

c(random     = eff_dim(sel_random(ctx, n_sel), ctx),
  truncation = eff_dim(sel_truncation(ctx, n_sel), ctx))
#>     random truncation 
#>    1.47395    1.40726

Decomposition by Heterotic Group

In hybrid maize the diversity between pools is the engine of heterosis and cannot be spent; the diversity within each pool is the fuel for future progress. Following the logic of subdivided populations (Caballero and Toro 2002; López-Cortegano et al. 2019), we compute molecular coancestry between lines \(\mathbf{f}^{L}\) and weight it by each line’s usage among the selected hybrids:

\[ \theta_A = \mathbf{w}_A' \mathbf{f}^{L} \mathbf{w}_A, \qquad \theta_B = \mathbf{w}_B' \mathbf{f}^{L} \mathbf{w}_B, \qquad \theta_{AB} = \mathbf{w}_A' \mathbf{f}^{L} \mathbf{w}_B, \]

with \(\mathbf{w}_A\) the vector of usage frequencies of pool-A lines.

rbind(random     = theta_pools(sel_random(ctx, n_sel), ctx),
      truncation = theta_pools(sel_truncation(ctx, n_sel), ctx))
#>             theta_A  theta_B theta_AB
#> random     0.713892 0.706238 0.632869
#> truncation 0.755958 0.727068 0.631451

A blind optimizer can keep global \(\theta\) acceptable while eroding one of the pools. Without the decomposition this goes unnoticed, and the consequence only shows up the following cycle.

Formalizing the Within/Between Split, and Where It Could Go Next

\(\theta_A\), \(\theta_B\), and \(\theta_{AB}\) as computed here are diagnostic — they are reported, not yet fed back into the objective. The subdivided-population literature offers a ready-made way to promote them into a tunable target. Caballero and Rodríguez-Ramilo (2010), used by López-Cortegano et al. (2019) to manage two heterotic-like pools simultaneously, partition total diversity as

\[ H_T = D_G + \lambda H_S, \qquad A_T = D_A + \lambda A_S, \]

where \(H_S\)/\(A_S\) are the within-pool components (our \(\theta_A\), \(\theta_B\), converted to diversity), \(D_G\)/\(D_A\) are the between-pool components (a function of \(\theta_{AB}\) relative to \(\theta_A,\theta_B\)), and \(\lambda \in [0, \infty)\) is a weight chosen by the breeder: \(\lambda = 0\) optimizes only between-pool divergence (protects heterosis, ignores each pool’s internal health), \(\lambda = 1\) weights both components equally, and \(\lambda \to \infty\) optimizes only within-pool diversity (protects each pool’s future options, ignores the cross). This maps directly onto the two constraints a maize breeder actually has in mind but currently applies only qualitatively: “don’t blend the pools together” versus “don’t paint either pool into a corner.” Turning \(\lambda\) into a second, explicit knob next to \(\alpha_{\max}\) — rather than only inspecting \(\theta_A/\theta_B/\theta_{AB}\) after the fact — is the natural next step if pool erosion shows up in practice; the current implementation reports the ingredients (\(\theta_A\), \(\theta_B\), \(\theta_{AB}\), and the per-pool Ne_lines_A/Ne_lines_B in R/01_metrics.R) but leaves the weighting decision to the analyst reading the report.

The Correct Baseline

Why Not Compare Against the 5000 × 5000 Matrix

The natural comparison — coancestry of the selected set against that of the whole population — is biased by construction. Applying equation (1) to both sets:

\[ \theta_S - \theta_N = \left(\frac{1}{n} - \frac{1}{N}\right)\left(\bar f_d - \bar f_o\right) \;>\; 0, \]

since \(\bar f_d > \bar f_o\) whenever individuals are not clones. A random sample of 200 already looks less diverse than the population of 5000, without any selection having occurred. The bias is purely from sampling and grows the smaller the sample.

Checking the formula numerically:

fd <- mean(diag(ctx$f)); fo <- mean(ctx$f[upper.tri(ctx$f)])
predicted_bias <- (1/n_sel - 1/ctx$N) * (fd - fo)

set.seed(11)
observed_bias <- mean(replicate(400, theta_group(sample.int(ctx$N, n_sel), ctx))) -
                 theta_group(seq_len(ctx$N), ctx)

c(predicted = predicted_bias, observed = observed_bias)
#>  predicted   observed 
#> 0.00345518 0.00350790

Note also that the off-diagonal mean of a random subset is an unbiased estimator of the population’s off-diagonal mean. In other words, the metric you already use is free of this bias — but it is also not comparable across sample sizes on the \(N_s\) scale.

Operational Definition of Loss

The “0% loss” reference is the distribution of random subsets of the same size, obtained by resampling:

\[ \alpha \;=\; \frac{GD_{\text{random}(n)} - GD_S}{GD_{\text{random}(n)}}. \]

So \(\alpha = 0\) means “as diverse as a random sample of the same size”, and \(\alpha < 0\) means more diverse than chance. Resampling also throws in the standard deviation, and hence the z-score of any strategy.

null <- null_distribution(ctx, n_sel, B = 400, B_full = 60)
c(GD_population = gene_diversity(seq_len(ctx$N), ctx),
  GD_reference = null$gd_ref, sd = null$gd_sd)
#> GD_population  GD_reference            sd 
#>    0.33111253    0.32767044    0.00143375
sapply(list(random = sel_random(ctx, n_sel),
            truncation = sel_truncation(ctx, n_sel),
            trunc_cap = sel_truncation_cap(ctx, n_sel)),
       alpha_loss, ctx = ctx, gd_ref = null$gd_ref)
#>     random truncation  trunc_cap 
#> 0.00183118 0.04319007 0.00452571

How to Set the α Limit

The acceptable limit should not be chosen a priori. Pure truncation — the greediest possible selection — defines the maximum attainable \(\alpha\). If that ceiling is lower than the intended limit, the constraint restricts nothing.

attainable_alpha_max <- alpha_loss(sel_truncation(ctx, n_sel), ctx, null$gd_ref)
c(attainable_alpha_max = attainable_alpha_max,
  intended_limit = 0.05,
  active_constraint = attainable_alpha_max > 0.05)
#> attainable_alpha_max       intended_limit    active_constraint 
#>            0.0431901            0.0500000            0.0000000

On the full dataset (2500 hybrids, 5000 markers, selecting 100) that ceiling came out at 3.63% — a 5% limit would be inoperative. The correct procedure is to trace the \(\alpha \times\) gain frontier and choose the knee of the curve.

Use Inside the Optimizer

Constraint Formulation, Not a Weighted Sum

With \(\mathbf{u}\) the multi-trait index and \(S\) the set of \(n\) selected individuals:

\[ \max_{S,\; |S| = n} \; \frac{1}{n}\sum_{i \in S} u_i \qquad \text{subject to} \qquad \alpha(S) \;\le\; \alpha_{\max}. \]

The common alternative, \(\max\; \bar u - \lambda\,\theta_S\), requires calibrating \(\lambda\), which has no direct interpretation. The constraint form preserves the operational meaning: “I accept losing at most \(\alpha_{\max}\) of diversity”. It is the same principle behind optimal contribution selection (OCS) (Meuwissen 1997), differing in that there contributions \(\mathbf{c}\) are continuous while here the problem is combinatorial (0/1 with equal weight), which motivates using differential evolution (Storn and Price 1997; Mullen et al. 2011).

Relation to the Standard OCS Formulation

Gómez-Romano et al. (2016) write the general OCS problem, for a vector of continuous contributions \(\mathbf{c}\), as

\[ \text{minimize} \quad \mathbf{c}'\mathbf{G}\mathbf{c} \qquad \text{subject to} \qquad \mathbf{c}'\mathbf{s} = 0.5,\;\; \mathbf{c}'\mathbf{d} = 0.5,\;\; c_i \ge 0, \]

with \(\mathbf{s}\)/\(\mathbf{d}\) indicating sex, and \(\mathbf{G}\) the coancestry matrix chosen for managing diversity (here, our \(\mathbf{f}\)). Our formulation is the special case of this problem restricted to \(c_i \in \{0, 1/n\}\) — a fixed number \(n\) of candidates contribute equally, none partially — with the minimization of \(\mathbf{c}'\mathbf{f}\mathbf{c}\) turned into a constraint (\(\alpha(S) \le \alpha_{\max}\)) and \(\bar u\) promoted to the objective. This restriction to equal, all-or-nothing contributions is exactly what makes the problem combinatorial and pushes the solution method from convex quadratic programming to differential evolution; Carvalheiro et al. (2010) used the same algorithm for continuous-contribution OCS, so DE is an established tool for this problem family, not a choice specific to the discrete case here. The ocs_relaxation() function in R/03_de_select.R implements the continuous relaxation of this restricted problem (Section @ref(convergence-diag)) precisely by dropping the \(c_i \in \{0, 1/n\}\) restriction back to \(0 \le c_i \le 1/n\) — it is the bridge between the two formulations, not a separate model.

A caveat carried over from the general OCS literature. Gómez-Romano et al. (2016) show that the predicted rate of coancestry in the next generation, \(E(\Delta f_{t+1}) = (\mathbf{c}'\mathbf{G}_t\mathbf{c} - f_t)/(1-f_t)\), is systematically biased downward relative to the coancestry actually realized after offspring are generated — by roughly a factor of two in their simulations with small candidate pools, shrinking as candidate pool size grows. The bias arises because \(\mathbf{c}'\mathbf{G}\mathbf{c}\) is an expectation over Mendelian segregation, and the realized draw has its own sampling variance on top of that expectation. This does not affect the \(\theta_S\) computed here on an already-realized hybrid population — \(\mathbf{f}\) is measured on real marker genotypes, not predicted from parental contributions, so there is no forward-prediction step to bias. It becomes relevant only if this pipeline is later extended to plan a further generation from the selected 200 hybrids (i.e., to predict their offspring’s coancestry from a contribution vector): at that point, the naive \(\mathbf{c}'\mathbf{f}\mathbf{c}\) prediction should be expected to underestimate realized coancestry, and the margin built into \(\alpha_{\max}\) should account for it.

make_fitness <- function(ctx, n_sel, alpha_max, gd_ref, penalty = 1000) {
  function(par) {
    idx  <- decode(par, ctx$N, n_sel)
    gd   <- 1 - mean(ctx$f[idx, idx])          # matrix route: 40k operations
    viol <- max(0, (gd_ref - gd) / gd_ref - alpha_max)
    -(mean(ctx$index[idx]) - penalty * viol)   # DEoptim minimizes
  }
}

Convergence Diagnostic

The problem’s continuous relaxation — allowing \(0 \le c_i \le 1/n\) with \(\sum_i c_i = 1\) instead of \(c_i \in \{0, 1/n\}\) — provides a valid upper bound, since every discrete solution is feasible under the relaxed problem. A large gap between the differential evolution result and that bound indicates the optimizer hasn’t converged, not that the problem is intrinsically hard.

In practice, seeding the initial population with heuristic solutions (greedy on \(\theta\), truncation with a per-parent usage cap) is decisive: without it the optimizer ends up below a plain greedy.

This mirrors a finding from a related but distinct combinatorial-selection problem. De Beukelaer et al. (2018), optimizing core-collection subsets with local search rather than DE, found that a basic stochastic hill-climber (random descent) was already competitive, that a considerably more complex genetic algorithm did not reliably beat it, and that the method which won — parallel tempering — won by combining many simple local searches rather than by being individually more sophisticated. The common thread with the warm-start result here: for this class of problem (select \(n\) of \(N\) to jointly optimize gain and diversity), the return on a smarter search strategy around a simple move (swap one candidate) consistently outweighs the return on a more elaborate single-solution search algorithm. A useful direction if the DE result ever looks unconvincing on the real 25k-marker data: run several independent DE chains from different warm starts (analogous to parallel tempering’s multiple replicas) rather than reaching for a fundamentally different optimizer.

Implementation: The Two-Stage Pipeline

Everything above is assembled into a two-stage pipeline, orchestrated by run_all.R and implemented in R/10_stage1.R and R/11_stage2.R. The split exists because the two stages have different costs and different reasons to be re-run: stage 1 (simulating or ingesting the hybrids) is done once per breeding cycle; stage 2 (the constrained selection) is cheap enough, and sensitive enough to the chosen \(\alpha_{\max}\) and trait weights, to be re-run many times against the same X/f/hybrids objects.

Stage 1 — From Lines to (X, f, hybrids)

# R/10_stage1.R
stage1_simulate <- function(cfg = sim_config) {
  d <- simulate_data(cfg)
  stage1_build(X = d$X, ped = d$ped, traits = d$traits, fL = d$fL)
}

stage1_build <- function(X, ped, traits, fL = NULL) {
  if (max(X) > 1) X <- X / 2          # accepts 0/1/2 or 0/0.5/1 coding
  stopifnot(nrow(X) == nrow(ped), nrow(X) == nrow(traits))
  hybrids <- data.frame(
    hybrid = seq_len(nrow(X)),
    line_A = as.integer(ped$a), line_B = as.integer(ped$b),
    traits
  )
  list(X = X, f = molecular_coancestry(X), hybrids = hybrids, fL = fL)
}

stage1_simulate() is the path used throughout this document. stage1_build() is the path for real data: it takes a hybrid marker matrix (any of 0/1/2 or 0/0.5/1 coding — Section @ref(f-molecular)’s \(x_{ik}\)), a two-column pedigree of parent-line indices, and the table of predicted trait values already produced by GBLUP outside this pipeline. It computes \(\mathbf{f}\) once, via molecular_coancestry() (the boxed identity in Section @ref(f-molecular)), and returns the same three-object contract regardless of which path produced it — the rest of the pipeline never needs to know whether X came from a simulation or a genotyping file.

Stage 2 — Selection Across an α Grid

# R/11_stage2.R (excerpt)
stage2_select <- function(X, f, hybrids, n_sel,
                          alphas = NULL, weights = NULL, fL = NULL,
                          include_references = TRUE,
                          B_null = 2000, NP = 300, itermax = 2000, ...) {
  ctx <- build_ctx_from_stage1(X, f, hybrids, fL, weights)

  # 1. Reference and ceiling (Sections 6-7)
  gd_rand   <- replicate(B_null, gene_diversity(sample.int(ctx$N, n_sel), ctx))
  gd_ref    <- mean(gd_rand)
  alpha_max <- alpha_loss(sel_truncation(ctx, n_sel), ctx, gd_ref)
  if (is.null(alphas)) alphas <- seq(0, alpha_max, length.out = 5)

  # 2. Warm start (Section "Convergence Diagnostic")
  seeds <- c(lapply(c(0, 1e-4, 2e-4, 3e-4, 5e-4, 1e-3, 3e-3),
                    function(w) sel_greedy(ctx, n_sel, w = w)),
             list(sel_truncation_cap(ctx, n_sel)))

  # 3. One DE run per alpha in the grid
  scenarios <- lapply(alphas, function(a)
    sel_de(ctx, n_sel, alpha_max = a, gd_ref = gd_ref,
          NP = NP, itermax = itermax, seeds = seeds))

  # 4. Metrics per scenario + N x n_scenarios 0/1 table
  # ...
}

Four things this function does that are easy to miss from the summary table alone, each traceable to a section above:

  1. The reference is recomputed from X/f, not hardcoded. gd_ref and alpha_max come from n_sel random draws and one truncation run on this dataset (Sections @ref(baseline) and “How to Set the α Limit”) — a different n_sel, a different set of hybrids, or real vs. simulated data all shift these numbers, which is why they must never be pasted in from a previous run.
  2. alphas = NULL produces a grid, not a single answer, spanning \([0, \alpha_{\max}]\) in five steps by default — the mechanism behind the gain-vs-diversity frontier (Section “Which Metric Belongs in the Inner Loop” and run_benchmark.R’s frontier.csv), available here without a second script.
  3. The same warm-start seeds serve every \(\alpha\) in the grid. Building them once and reusing them (rather than re-deriving per scenario) is what keeps five-plus DE runs affordable, and is the direct implementation of the Convergence Diagnostic finding above.
  4. include_references = TRUE appends non-DE strategies (pure truncation, truncation with a parental cap, pure-diversity greedy, one random draw) as extra columns in the same output table, so the DE scenarios are never read in isolation from their baselines.

res$selection is one row per hybrid (all ctx$N of them, not just the selected ones) and one 0/1 column per scenario, so “was hybrid 472 selected under the strictest diversity constraint” is a single lookup rather than a set intersection. n_scenarios — the row sum across scenario columns — is a free robustness signal: a hybrid chosen at every point along the \(\alpha\) grid is a safe pick regardless of how much diversity loss ends up being acceptable; a hybrid that appears only when \(\alpha_{\max}\) is loosest is a gain/diversity trade that only survives if that laxer target is the one adopted. run_all.R writes this table to report/selection_by_scenario.csv and the companion metrics table to report/metrics_by_scenario.csv, unmodified from what stage2_select() returns — the CSVs are exactly res$selection and res$metrics, not a reshaped summary of them.

Operational Summary

Step Object Formula
1 Hybrid genotype \(M^{H}_{(ab)k} = (M^{L}_{ak} + M^{L}_{bk})/2\)
2 Trait prediction VanRaden \(\mathbf{G}\), \(\mathbf{Z}\mathbf{Z}'/2\sum p_kq_k\)
3 Diversity \(\mathbf{f} = (2\mathbf{X}\mathbf{X}' - \mathbf{s}\mathbf{1}' - \mathbf{1}\mathbf{s}' + m\mathbf{J})/m\)
4 Group coancestry \(\theta_S = \mathbf{1}'\mathbf{f}_S\mathbf{1}/n^2\)
5 Gene diversity \(GD = 1 - \theta_S \equiv H_e\)
6 Interpretable scale \(N_s = 1/(2\theta_S)\)
7 Baseline resampling of \(n\) individuals, not the full population
8 Loss \(\alpha = (GD_{\text{random}} - GD_S)/GD_{\text{random}}\)
9 Pipeline stage1_simulate/stage1_build \(\to\) stage2_select \(\to\) selection + metrics tables

Mistakes to avoid, in order of severity:

  1. Computing coancestry over centered \(\mathbf{G}\) — a meaningless result.
  2. Comparing the \(n \times n\) submatrix against the \(N \times N\) matrix — sampling bias read as diversity loss.
  3. Fixing \(\alpha_{\max}\) before knowing the attainable ceiling.
  4. Omitting the diagonal from \(\theta\) — small impact in an \(F_1\) population, but required for the \(N_s\) scale to be meaningful.
  5. Running the optimizer without a warm start and concluding the problem is hard.
  6. Treating \(GD\)/\(N_s\) as a certificate against long-run drift — they measure homozygosity-based diversity (\(F_{\text{hom}}\)), which under active management can diverge from drift-based diversity (\(F_{\text{drift}}\), Meuwissen et al. (2020)). Fine for one round of hybrid selection; track allelic richness too if planning several breeding cycles.
