4  Response to selection: the other half of the objective

Every chapter so far measures what selection spends. None of them writes down what it buys.

That asymmetry is not cosmetic. Chapter 23 will show a constrained programme overtaking an unconstrained one after several cycles, at a crossover cycle that varies with the simulation seed, and the book can report that because it simulated it – not because anything in the preceding chapters predicts it. A reader who wants to know when the crossover arrives in their programme has no way to find out except to re-run the simulation with their own parameters.

The quantitative genetics that answers such questions is older than any of the genomic machinery here, and this chapter installs it: the variance selection acts on, the equation that turns that variance into gain, and the classical index theory that turns out to be the direct ancestor of this book’s \(\alpha\) constraint.

The data come from simulate_pools(), a lighter form of the generator that Chapter 6 builds step by step: pool allele frequencies drawn under the Balding-Nichols model with parameter fst from ancestral frequencies, homozygous lines GL (0/1), and the complete A \(\times\) B factorial of hybrids X (0/0.5/1). It adds a trait: n_qtl markers taken at random as quantitative trait loci with independent standard-normal effects beta (zero elsewhere), and an index equal to the standardised true genetic value plus independent normal noise of variance \(1/h^2 - 1\), then standardised: before that last step the genetic value has unit variance, so \(h^2\) is the share of the index variance it contributes in expectation.

Show code 
sim <- simulate_pools(n_A = book_cfg$n_pool_A, n_B = book_cfg$n_pool_B,
                      m = book_cfg$m, fst = 0.15, n_qtl = 300, h2 = 0.5, seed = 1)
X  <- sim$X                       # N x m hybrids, 0/0.5/1
gv <- drop(X %*% sim$beta)        # true genetic value, known here by construction
I  <- sim$index                   # what the breeder actually sees
c(hybrids = nrow(X), markers = ncol(X), qtl = sum(sim$beta != 0))
#> hybrids markers     qtl 
#>     625    2000     300

4.1 The breeder’s equation, and how well it does here

Response to one round of truncation selection is

\[R \;=\; i \, r \, \sigma_A \tag{4.1}\]

with \(i\) the selection intensity (a property of the selected fraction alone), \(r\) the accuracy of the criterion as a predictor of genetic value, and \(\sigma_A\) the additive standard deviation (Falconer and Mackay 1996, ch. 11). Here the genetic value of the hybrids is the vector \(\mathbf{X}\boldsymbol\beta\) (gv), purely additive in the marker coding by construction of simulate_pools(), so \(\sigma_A\) is estimated by sd(gv). sel_intensity() returns \(i\); later chapters use it inside the usefulness criterion (Chapter 13) and in a replicated check of this equation (Chapter 9). Table 4.1 sets the predicted response of Equation 4.1 beside the realised one for the top 60 hybrids on the index.

Show code 
n_sel <- 60
N     <- nrow(X)
i_norm <- sel_intensity(n_sel / N)
r      <- cor(I, gv)
sel    <- order(I, decreasing = TRUE)[seq_len(n_sel)]

fmt(data.frame(`intensity i` = i_norm, `accuracy r` = r,
               `additive s.d. (sim. units)` = sd(gv),
               `predicted response (sim. units)` = i_norm * r * sd(gv),
               `realised response (sim. units)` = mean(gv[sel]) - mean(gv),
               check.names = FALSE), 3)

In this single draw (seed 1) the equation overpredicts, by about 13 percent. Table 4.2 splits that gap into the intensity and the regression parts.

Show code 
i_real <- (mean(I[sel]) - mean(I)) / sd(I)
b      <- cov(gv, I) / var(I)                 # regression of value on criterion
fmt(data.frame(
  `intensity, normal theory` = i_norm,
  `intensity, realised`      = i_real,
  `response with realised intensity (sim. units)` = i_real * r * sd(gv),
  `response from regression (sim. units)` = b * (mean(I[sel]) - mean(I)),
  `realised response (sim. units)`        = mean(gv[sel]) - mean(gv),
  `index skewness` = mean(scale(I)^3), check.names = FALSE), 3)

Two identities can be read off it. The response from regression and the response with realised intensity are the same quantity written twice, since \(b\,S_I = i\,r\,\sigma_A\) identically, with \(S_I\) the selection differential on the index. The chunk below asserts it.

Show code 
stopifnot(isTRUE(all.equal(b * (mean(I[sel]) - mean(I)), i_real * r * sd(gv))))

With \(N =\) 625 candidates and \(n =\) 60 selected, \(i = \varphi(z)/(n/N)\), with \(z\) the standard-normal truncation point that leaves a fraction \(n/N\) above it and \(\varphi\) the standard-normal density, is the intensity of an infinitely large normal population (Falconer and Mackay 1996, ch. 11). At this finite \(N\) the expected standardised mean of the top \(n\) of \(N\) independent normal draws is smaller. A single draw cannot tell whether the remaining gap is structural or sampling, so Table 4.3 repeats the same simulate_pools() call over 30 seeds, and the finite-\(N\) intensity is estimated from 4000 normal samples.

Show code 
one_seed <- function(s) {
  sm <- simulate_pools(n_A = book_cfg$n_pool_A, n_B = book_cfg$n_pool_B,
                       m = book_cfg$m, fst = 0.15, n_qtl = 300, h2 = 0.5,
                       seed = s)
  g  <- drop(sm$X %*% sm$beta)
  Ix <- sm$index
  top <- order(Ix, decreasing = TRUE)[seq_len(n_sel)]
  pred <- sel_intensity(n_sel / length(Ix)) * cor(Ix, g) * sd(g)
  c(rel_gap = 1 - (mean(g[top]) - mean(g)) / pred,
    i_real  = (mean(Ix[top]) - mean(Ix)) / sd(Ix),
    skew    = mean(scale(Ix)^3))
}
rep_seeds <- t(vapply(1:30, one_seed, numeric(3)))
gap_se <- sd(rep_seeds[, "rel_gap"]) / sqrt(nrow(rep_seeds))
stopifnot(abs(mean(rep_seeds[, "rel_gap"])) < 2 * gap_se)   # the claim below

set.seed(11)
i_finite <- replicate(4000, {
  z <- rnorm(N)
  (mean(sort(z, decreasing = TRUE)[seq_len(n_sel)]) - mean(z)) / sd(z)
})

fmt(data.frame(
  quantity = c("relative gap 1 - realised/predicted", "realised intensity",
               "index skewness"),
  `mean over seeds` = colMeans(rep_seeds),
  `s.e.`            = apply(rep_seeds, 2, sd) / sqrt(nrow(rep_seeds)),
  minimum           = apply(rep_seeds, 2, min),
  maximum           = apply(rep_seeds, 2, max),
  row.names = NULL, check.names = FALSE), 3)

Over the 30 seeds the mean relative gap is 0.006 (standard error 0.016), the prediction exceeds the realised response in 19 of 30 seeds, and the mean realised intensity is 1.776 against a finite-\(N\) normal expectation of 1.771 (s.d. 0.044) and the infinite-population value 1.774.

The replicated mean gap is within two standard errors of zero, so at this scale the seed-1 overprediction is consistent with sampling variation, and the equation shows no detectable bias; the replicated AlphaSimR sweep of Chapter 9 reaches the same reading. One limit applies: only the teaching scale (25 + 25 lines, 2000 markers, Balding-Nichols fst = 0.15) was measured, so nothing here says how the gap behaves at production scale or under selection across cycles.

4.2 Genic variance, and what it has to do with gene diversity

The additive variance in Equation 4.1 is not a fixed property of the population. Split it in two.

Genic variance is what the loci would contribute if they were independent:

\[V_{\text{genic}} \;=\; \sum_k \beta_k^2 \operatorname{Var}(x_k) \tag{4.2}\]

with \(\beta_k\) the effect of marker \(k\) and \(x_k\) its hybrid genotype.

Realised variance is what the population actually has, \(\operatorname{Var} (\mathbf{X}\boldsymbol\beta)\), which is the sum of the whole covariance matrix rather than only its diagonal. The difference is exactly the gametic-phase disequilibrium term (Bulmer 1971), which Table 4.4 evaluates for the seed-1 draw:

\[\operatorname{Var}(\mathbf{X}\boldsymbol\beta) - V_{\text{genic}} \;=\; 2\sum_{k<l}\beta_k\beta_l \operatorname{Cov}(x_k, x_l) \tag{4.3}\]

Show code 
Cx  <- cov(X)
ld  <- sum(outer(sim$beta, sim$beta) * Cx) - sum(sim$beta^2 * diag(Cx))
stopifnot(isTRUE(all.equal(var(gv) - genic_var(X, sim$beta), ld)),
          isTRUE(all.equal(genic_var(X, sim$beta), ref_genic_var(X, sim$beta))))
fmt(data.frame(
  quantity = c("realised variance", "genic variance",
               "disequilibrium term", "deviation from oracle"),
  `value (sim. units squared)` = c(var(gv), genic_var(X, sim$beta),
            var(gv) - genic_var(X, sim$beta),
            abs(genic_var(X, sim$beta) - ref_genic_var(X, sim$beta))),
  check.names = FALSE), 4)

How does \(V_{\text{genic}}\) relate to gene diversity? Let \(p_{Ak}\) and \(p_{Bk}\) be the frequencies of the allele coded 1 at locus \(k\) among the inbred lines of pools A and B, \(q = 1 - p\) (so \(\bar q_k = 1 - \bar p_k\)), and \(\bar p_k = (p_{Ak} + p_{Bk})/2\) the hybrid-pool frequency. A hybrid of the complete A \(\times\) B factorial carries \(x_k = (u_k + v_k)/2\), with \(u_k \in \{0, 1\}\) the allele of its pool-A parent and \(v_k \in \{0, 1\}\) that of its pool-B parent (the \(u_{ik}\), \(v_{jk}\) of Section 5.10 without the line index), drawn independently from the two pools, so over the factorial (population-variance scale)

\[\operatorname{Var}(x_k) \;=\; \frac{p_{Ak}q_{Ak} + p_{Bk}q_{Bk}}{4} \;=\; \frac{\bar p_k \bar q_k}{2} - \frac{(p_{Ak} - p_{Bk})^2}{8}. \tag{4.4}\]

Show code 
pA <- colMeans(sim$GL[sim$pool == "A", ])
pB <- colMeans(sim$GL[sim$pool == "B", ])
pH <- (pA + pB) / 2
v_pop <- colMeans(X^2) - colMeans(X)^2
stopifnot(isTRUE(all.equal(v_pop, (pA * (1 - pA) + pB * (1 - pB)) / 4)),
          isTRUE(all.equal(v_pop, pH * (1 - pH) / 2 - (pA - pB)^2 / 8)))
ok <- pH > 0 & pH < 1
c(ratio_min = min(v_pop[ok] / (pH * (1 - pH))[ok]),
  ratio_max = max(v_pop[ok] / (pH * (1 - pH))[ok]))

The per-locus variance entering \(V_{\text{genic}}\) (Equation 4.2) is therefore not proportional to \(\bar p_k \bar q_k\): the ratio \(\operatorname{Var}(x_k)/(\bar p_k \bar q_k)\) ranges from 0.107 to 0.5 across these loci. Gene diversity of the hybrid pool, \(\frac{1}{m}\sum_k 2 \bar p_k \bar q_k\), contains the between-pool divergence \((p_{Ak} - p_{Bk})^2\) that Equation 4.4 subtracts (since \(2\bar p_k\bar q_k = p_{Ak}q_{Ak} + p_{Bk}q_{Bk} + (p_{Ak} - p_{Bk})^2/2\)), the between-pool term of the partition of Chapter 3, while \(V_{\text{genic}}\) among hybrids sees only the within-pool part, weighted by squared effect. The inference is that gene diversity is a proxy for genic variance only through its within-pool part, and only if effect sizes are unrelated to which loci lose diversity; this chapter does not test the second condition.

The proxy is incomplete in two further ways. Gene diversity weights every locus equally, so it cannot distinguish a marker carrying half the genetic variance from one carrying none. And – more seriously –

WarningThe frequency-based metrics cannot see the disequilibrium term

\(\theta\), \(GD\), \(N_s\), allelic richness, F_hom and F_drift – including \(\theta\), the only metric the differential evolution (DE) selector constrains – are all functions of allele frequencies one locus at a time. The covariance term of Equation 4.3 does not move a single allele frequency. eff_dim() is the exception: it is computed from the spectrum of the double-centred \(f\), a multilocus quantity, so it does respond to disequilibrium, but it weights loci by nothing, not by effect. A flat gene diversity trajectory therefore does not imply flat additive variance: reading it as one puts the error of Equation 4.3, the whole disequilibrium term, into \(\sigma_A^2\) and from there into the predicted \(R\) of Equation 4.1. Chapter 24 measures how far apart the two can travel.

4.3 Combining ability as the additive part

Additive variance is the variance of breeding values, not of genotypic values, and in a two-pool hybrid population the average effect of an allele substitution depends on which pool it is substituted into. The exact orthogonal split of a hybrid value into general and specific combining ability (GCA, SCA) (Sprague and Tatum 1942) is developed in Section 5.10, in the next chapter; it is used here ahead of that derivation: each line’s GCA is its average effect against the opposite pool, i.e. the additive part relative to that tester pool, never a property of the line alone. The chunk below applies it to an illustrative, dominance-only value \(H\) = heterosis_value(X, d), with deviations \(d_k \sim N(0.3, 0.1^2)\) drawn here and unrelated to \(\boldsymbol\beta\). Its shares are shares of that illustrative heterosis, not of the genetic variance of gv.

Show code 
set.seed(7)
d  <- rnorm(ncol(X), 0.3, 0.1)                  # dominance deviations
U  <- sim$GL[sim$pool == "A", ]
V  <- sim$GL[sim$pool == "B", ]
gs <- heterosis_gca_sca(U, V, d)
H  <- heterosis_value(X, d)

nA <- nrow(U); nB <- nrow(V)
gA <- rep(gs$gca_A, times = nB)                 # ped varies pool A fastest
gB <- rep(gs$gca_B, each  = nA)
sc <- as.vector(gs$sca)

stopifnot(isTRUE(all.equal(H, gs$mu + gA + gB + sc)),
          isTRUE(all.equal(var(H), var(gA) + var(gB) + var(sc))),
          max(abs(c(cov(gA, gB), cov(gA, sc), cov(gB, sc)))) < 1e-10)
c(reconstruction_dev = max(abs(H - (gs$mu + gA + gB + sc))),
  var_H              = var(H),
  sum_of_components  = var(gA) + var(gB) + var(sc),
  identity_dev       = abs(var(H) - (var(gA) + var(gB) + var(sc))))

The three components are orthogonal, so their variances add exactly. Table 4.5 gives the shares.

Show code 
p <- c(gca_A = var(gA), gca_B = var(gB), sca = var(sc))
fmt(data.frame(component = names(p), variance = p,
               share = p / sum(p)), 3)

gca_A and gca_B are the part of \(H\) that main effects of the parent lines, each against the opposite pool, can express; sca is the line-by-line interaction they cannot. How each share responds to recurrent selection across cycles is not measured in this chapter.

4.4 What weights = NULL is assuming

stage2_select() defaults (weights = NULL) to equal weight on every trait, and every chapter of this book including Chapter 25 takes that default. The criteria it weights are not phenotypes but the predicted trait values \(\hat{\mathbf{g}}\) of the hybrids (hybrids columns, passed to build_ctx() as traits). build_ctx() standardises each column before weighting, so the default index is \(\sum_j \hat g_j / \operatorname{sd}(\hat g_j)\), up to a positive affine transformation that does not change the ranking. In trait units that is the index \(\mathbf{a}'\hat{\mathbf{g}}\) with economic weights \(a_j = 1/\operatorname{sd}(\hat g_j)\). What the default assumes is therefore an economic statement: one standard deviation of predicted value is worth the same in every trait. It is a choice, not a neutral one.

Whether \(\mathbf{a}'\hat{\mathbf{g}}\) is the best index for those \(\mathbf{a}\) is a separate question, and the answer depends on what \(\hat{\mathbf{g}}\) is. Let \(W = \mathbf{a}'\mathbf{g}\) be the aggregate genotype (the breeding objective), with \(\mathbf{g}\) the vector of the traits’ genetic values (one entry per trait; not a vector over individuals). The weights \(\mathbf{b}\) on a vector of criteria \(\boldsymbol\xi\) that maximise the correlation between \(\mathbf{b}'\boldsymbol\xi\) and \(W\) are \(\operatorname{Var}(\boldsymbol\xi)^{-1}\operatorname{Cov}(\boldsymbol\xi, \mathbf{g}')\,\mathbf{a}\). When \(\boldsymbol\xi = \hat{\mathbf{g}}\) is the multi-trait best linear unbiased predictor (BLUP) of \(\mathbf{g}\), \(\operatorname{Cov}(\hat{\mathbf{g}}, \mathbf{g}') = \operatorname{Var}(\hat{\mathbf{g}})\), so \(\mathbf{b} = \mathbf{a}\): weighting the predictions by the economic weights is then the optimum, not a departure from it. The condition fails in general for predictions that are not BLUP of \(\mathbf{g}\), single-trait BLUPs of genetically correlated traits included.

When \(\boldsymbol\xi\) is instead the vector of phenotypic records \(\mathbf{y} = \mathbf{g} + \mathbf{e}\), \(\mathbf{e}\) independent of \(\mathbf{g}\), with \(\operatorname{Var}(\mathbf{y}) = \boldsymbol\Sigma_P\) and \(\operatorname{Cov}(\mathbf{y}, \mathbf{g}') = \boldsymbol\Sigma_G\), the same expression is the Smith-Hazel index (Smith 1936; Hazel 1943):

\[\mathbf{b} \;=\; \boldsymbol\Sigma_P^{-1}\boldsymbol\Sigma_G\mathbf{a}, \tag{4.5}\]

with \(\boldsymbol\Sigma_P\) and \(\boldsymbol\Sigma_G\) the phenotypic and genetic covariance matrices of the traits (P and G in the code; \(\boldsymbol\Sigma_G\) is not the relationship matrix \(\mathbf{G}\)) and \(\mathbf{a}\) the economic weights. Table 4.6 evaluates Equation 4.5 for a two-trait example.

Show code 
P <- matrix(c(4.0, 1.2, 1.2, 1.0), 2)      # phenotypic covariance
G <- matrix(c(2.0, 0.3, 0.3, 0.3), 2)      # genetic covariance
a <- c(1, 1)                               # equal economic weight
stopifnot(all(eigen(G, only.values = TRUE)$values > 0),      # G is a covariance
          all(eigen(P - G, only.values = TRUE)$values > 0))  # so is P - G

fmt(data.frame(trait = c("yield", "moisture"),
               `economic weight` = a,
               `Smith-Hazel weight` = index_smith_hazel(P, G, a),
               check.names = FALSE), 3)

Equal economic weights do not give equal index weights on phenotypes here. \(\mathbf{b}\) is proportional to \(\mathbf{a}\) if and only if \(\mathbf{a}\) is an eigenvector of \(\boldsymbol\Sigma_P^{-1}\boldsymbol\Sigma_G\). A sufficient condition is \(\boldsymbol\Sigma_G = c\,\boldsymbol\Sigma_P\) – every trait with heritability \(c\) and genetic correlations equal to the phenotypic ones – which requires neither equal variances nor uncorrelated traits.

Show code 
stopifnot(isTRUE(all.equal(index_smith_hazel(P, 0.5 * P, a), 0.5 * a)))
# BLUP of g from one record per trait (known means): ghat = G P^-1 y.
K <- G %*% solve(P)
stopifnot(isTRUE(all.equal(drop(solve(K %*% P %*% t(K), K %*% G) %*% a), a)),
          isTRUE(all.equal(drop(t(K) %*% a), index_smith_hazel(P, G, a))))

The chunk also checks the two statements that tie the phenotypic and the predicted index together, for the BLUP from one record per trait with known means, \(\hat{\mathbf{g}} = \boldsymbol\Sigma_G\boldsymbol\Sigma_P^{-1}\mathbf{y}\): \(\operatorname{Var}(\hat{\mathbf{g}})^{-1}\operatorname{Cov}(\hat{\mathbf{g}}, \mathbf{g}')\,\mathbf{a} = \mathbf{a}\), and \(\mathbf{a}'\hat{\mathbf{g}}\) is the Smith-Hazel index \(\mathbf{b}'\mathbf{y}\) of Table 4.6. So the gap between \(\mathbf{b}\) and \(\mathbf{a}\) in that table is a property of an index on phenotypes; it is not a defect of weights = NULL, whose criteria are predictions. What the default does assume is the economic weighting \(a_j = 1/\operatorname{sd}(\hat g_j)\), and that the predictions behave as multi-trait BLUP; this chapter tests neither against a real breeding objective.

4.5 The \(\alpha\) constraint is a restricted index

Chapter 15 will argue that a diversity budget is approvable where a weighted sum is not: “I accept losing five percent” is a sentence a breeding committee can sign, and “diversity is worth \(\lambda\) index units” is not.

That argument is usually presented as a point about human decision-making. It is older and harder than that. Kempthorne and Nordskog (1959) posed exactly the same problem – maximise aggregate gain subject to zero expected change in a specified direction – and solved it. In the \(\mathbf{C} = \boldsymbol\Sigma_G\mathbf{R}\) form used by index_restricted() (algebraically equivalent; not necessarily their notation), with \(\mathbf{R}\) the \(n_t \times n_r\) matrix of restricted directions for \(n_t\) traits and \(n_r\) restrictions:

\[\mathbf{b} \;=\; \boldsymbol\Sigma_P^{-1}\left[\boldsymbol\Sigma_G\mathbf{a} - \mathbf{C} (\mathbf{C}'\boldsymbol\Sigma_P^{-1}\mathbf{C})^{-1}\mathbf{C}'\boldsymbol\Sigma_P^{-1} \boldsymbol\Sigma_G\mathbf{a}\right], \qquad \mathbf{C} = \boldsymbol\Sigma_G\mathbf{R} \tag{4.6}\]

Table 4.7 compares it with the unrestricted index of Table 4.6 when moisture is held at zero gain.

Show code 
R  <- cbind(c(0, 1))                       # hold moisture at zero gain
b_r <- index_restricted(P, G, a, R)
b_u <- index_smith_hazel(P, G, a)

fmt(data.frame(
  index = c("Smith-Hazel", "restricted"),
  `weight on yield`    = c(b_u[1], b_r[1]),
  `weight on moisture` = c(b_u[2], b_r[2]),
  `expected gain in moisture (trait units)` = c(drop(crossprod(R, G %*% b_u)),
                                                drop(crossprod(R, G %*% b_r))),
  check.names = FALSE), 4)
stopifnot(max(abs(crossprod(R, G %*% b_r))) < 1e-12)

The restricted index moves the restricted trait by exactly zero – not approximately, not on average. That is the property distinguishing a restriction from a penalty. What \(\alpha\) inherits is the restriction, not the zero: it is an inequality, \(\alpha \le \alpha_{\max}\), on the loss of gene diversity relative to a random subset of the same size (Section 11.9), so the loss is bounded rather than held at zero, and Chapter 15 works out what changes when the equality restriction becomes an inequality.

ImportantWhat is genuinely new in this book, then

Not the idea of constraining rather than pricing: that is 1959. What is new is the restricted direction. Kempthorne and Nordskog (1959) restricted a trait. This book restricts the loss of molecular gene diversity, which is not a trait, has no economic weight, and is measured on a matrix rather than a phenotype. The algebra of restriction carries over; the object being restricted does not.

Stating the lineage makes Chapter 15 stronger, not weaker. A theorem from 1959 stands behind the move.

4.6 Where this connects

Chapter 10 and Chapter 11 measure the allele frequencies from which, through Equation 4.4, the genic variance defined here is built; the link to variance runs through the within-pool part only. Chapter 14 measures the \(r\) this chapter took as given, and Finding 5 of Chapter 12 shows what happens when it is assumed rather than measured. Chapter 15 is where the restricted index becomes the \(\alpha\) constraint, and Chapter 24 is where the disequilibrium term this chapter isolated (Equation 4.3) turns out to matter more than Equation 4.1 suggests. The next chapter, Chapter 5, completes the Foundations part with the dominance side of the hybrid value; the Simulation part then opens with Chapter 6, which builds step by step the two-pool hybrid populations that simulate_pools() drew here in one call.
