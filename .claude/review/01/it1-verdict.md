# 01-coancestry -- verdict, iteration 1

VERDICT: REJECTED

DISQUALIFYING FAILURES
- 01-D1 [criterion 1] book/01-coancestry.qmd:101-103, end of @sec-why-not-g -- "In a *subset* the sum is not zero, but the quantity is still centered: it oscillates around zero, takes negative values". This is false. G = ZZ'/(2 sum pq) is positive semidefinite, so for any subset S, 1_S' G 1_S = ||Z'1_S||^2 / (2 sum pq) >= 0, and a subset sum can never be negative. Its expectation for a random subset of size n is positive and depends on n/N, so it does not oscillate around zero either. Some individual off-diagonal elements are negative, but that is a different claim from the one made. The argument that G "cannot measure diversity" in a subset therefore rests on a property G does not have. (Consumes 01-R1.)
- 01-D2 [criteria 1, 5] book/01-coancestry.qmd:170-173, "Reading the diagonal" -- "The excess above 0.5 measures exactly the fraction of markers at which the two parent lines carry the same allele". This is off by a factor of 2. From the definition at :123-124, f_ii = 0.5 + h_i/2, with h_i the homozygous fraction, so the excess is h_i/2. The chunk immediately below (:178, molecular_F = 2*fd - 1) computes h_i correctly as twice the excess. The prose and the code beneath it contradict each other. (Consumes 01-R2.)
- 01-D3 [criteria 1, 2] book/01-coancestry.qmd:205-212, "f is not an ad hoc substitute" -- "Structurally that is f" and "f is the member of the VanRaden family that has an absolute scale". Both are wrong. With p_k = 0.5 and the 0/1/2 coding of :59-62, G_0.5 = (M-1)(M-1)'/(m/2) = 4f - 2J. That is an affine function of f, not f: its entries lie in [-2, 2], so they are signed, and it is not a member of [0, 1]. G_0.5 and f order selections identically only when the contributions are normalised (c'Jc = 1 with sum c = 1). The text uses this condition but never states it. The error spreads outside this chapter: book/05-genomic-era.qmd:118 says "G_0.5 is the matrix this book calls f -- see @sec-coancestry". The word "proportional" at :205 quotes Meuwissen et al. (2020) faithfully (01-B6), but the identification at :206 and :210 is the author's own and is not correct. (Consumes 01-R3.)
- 01-D4 [criterion 7] book/01-coancestry.qmd:202 (@toro2014) -- the bib entry resolves (doi:10.1111/age.12140) to Doherty, Farrelly & Meade (2014), a paper on comparative epigenetics in cattle. The rendered book therefore attributes the G_0.5 result to a paper that does not contain it. (Consumes 01-B1.)
- 01-D5 [criterion 7] book/01-coancestry.qmd:65, :92, :116, :133 -- named results with no source: "VanRaden's first parametrisation" (:65), the status number N_s = 1/(2 theta) (:92), Malecot's coancestry (:116) and f_ii = (1 + F_i)/2 (:133). - 01-D6 [criterion 7] book/01-coancestry.qmd:120 (@caballero2000) -- this citation is UNSUPPORTED for molecular (IBS) coancestry. According to the refcheck, the Genet. Res. 75:331-343 abstract deals only with pedigree tools and does not mention markers, and the full text could not be reached. The attribution could not be confirmed, so I record it as unsupported, not as false. (Consumes 01-B2; 01-B8 for caballero2002 also remains unverified.)
- 01-D7 [criterion 4] book/01-coancestry.qmd:231-234 -- "The test suite asserts `sum(G) == 0` precisely so that a future change which silently starts feeding G to a diversity metric fails loudly". The test does not do this. tests/testthat/test-metrics.R:19-23 checks a property of ctx$G alone, |sum(G)| < 1e-6 N^2, which is a tolerance and not equality. It is blind to which matrix any metric consumes. The test that would catch G being used in place of f is the [0, 1] bound on ctx$f at test-metrics.R:13-17. The protection that the prose describes as fact does not exist in the cited test. (Includes 01-R6.)
