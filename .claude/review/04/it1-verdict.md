# 04-population-sizing -- verdict, iteration 1

VERDICT: REJECTED

DISQUALIFYING FAILURES

- 04-D1 [criterion 1] book/04-population-sizing.qmd:119-121, "Known bias" -- "-2.0% in junction number" is the single-meiosis Haldane ratio r/d - 1 at d = 2 cM. It is not the bias of the quantity the simulator counts. An F4 haplotype has accumulated about 1.75 L junctions over three meioses, and two junctions anywhere in the same 2 cM interval cancel. Treating ancestry as a two-state process with rate 1.75/M gives (1 - e^{-0.07})/0.07 = 0.966, i.e. about -3.4%. The audit (04-R1) measured -3.7% on a live panel. The chapter's own cached grid has SSD `junc` at 27.6-28.6 against an expected 1.75 x 16.7 = 29.2 (-2% to -6%), syn1 at -5.1% and syn2 at -6.1%. The claim "`spacing_cM = 1` gives a faithful count" was not measured either, and the same argument puts it near -1.7%. The 04-refs "checked, no finding" verdict on this line covers only the single-meiosis arithmetic, not the F4 count.
- 04-D2 [criteria 1, 5] qmd:331, :340, :344 -- "Twelve selfed F1 plants already put the expected number of lost loci below one" contradicts the chunk printed directly above it (qmd:327-328). With `h_res = 0.05, n_loci_eff = 5000`, expected_loci_lost is 1.953 at n = 8, 0.977 at n = 9, 0.488 at n = 10 and 0.122 at n = 12. The threshold is therefore 9 with the code as written, or 10 if both parents are counted (04-D3). "Already" points the wrong way. The Working-numbers rows "8-15 selfed" and "12 plants put expected lost loci below 1" carry the same wrong number (04-R2, 04-B8).
- 04-D3 [criterion 1] R/06_f2size.R:584-589 against qmd:320-324 and the roxygen at R/06:567-571 -- the prose and the documentation both say "each parent still segregates at a fraction of loci". That makes the segregating count 2 x h_res x n_loci_eff. The function computes h_res x n_loci_eff x 2(1/2)^n, which counts one parent only. The 2(1/2)^n per-locus loss is correct. The quantity reported is not the one described: it is half of it (04-R3, package defect).
- 04-D4 [criteria 3, 5] qmd:338-350, Working-numbers table -- these values are hand-typed and cannot be traced to the grid. "120 to retain diversity": 120 is not a grid point (the grid is N = 10, 30, ..., 390). "250-400": 400 lies outside the tested range (max 390), so the recommendation extrapolates past the data. "+280 plants buy +0.005 of D" is a 120 -> 400 step that was never simulated. The nearest measured steps are 110 -> 390 = +0.0067 and 130 -> 390 = +0.0049. "250-400 for multilocus selection" is also recommended where the chapter's own curve gives P = 0.37 (k = 8) and 0.07 (k = 10) at the largest N, so the objective that motivates the row is not met anywhere in the recommended range (04-R4).
- 04-D5 [criteria 2, 3] qmd:272-286, saturation table, and R/06_f2size.R:648-651 -- "Saturates near" is never defined: the text declares no threshold (marginal gain per 20 plants, fraction of the asymptote, P >= 0.95). The intervals "100-120", "60-80" and "200-260" therefore have no criterion they can be checked against. The SSD marginal gains past N = 110 (0.0005, 0.0018, 0.0006, ..., -0.0011, 0.0020, -0.0001) are the same size as the Monte Carlo noise, as the negative steps show, and no dispersion is reported. The "Recovery of 5 loci 200-260" row reads off a curve built from replicate 1 only (one population per N). That curve is non-monotone (k = 5: 0.887 at N = 170, 0.847 at N = 190) and first reaches 0.95 at N = 270, outside the stated interval. The multilocus curve also sits systematically below the no-distortion closed form (k = 5, N = 110: 0.62 vs 0.83) because all three distorters act against P2. The chapter never states this, although it governs every number in the row (04-R5, 04-R7).
- 04-D6 [criteria 4, 5] qmd:194, heading "The diversity curve saturates at 0.988, not at 1" -- 0.988 is the single grid value at N = 390, D = 0.98863, which rounds to 0.989. It is not a limit. The curve is still rising (+0.0067 from 110 to 390). The distortion gap reported flat at 0.0087-0.0108 (04-audit) puts the asymptote near 0.990. A finite-N observation is presented as the saturation value (04-R6).
- 04-D7 [criteria 2, 4] qmd:84-86, :221-235, with R/06_f2size.R:330-334 and f2_opt$beta_bulk = 6 -- `bulk_weights()` gives larger seed contributions to plants with more P1 genome. Loss of P2 (donor) ancestry under the bulk is therefore the model's input, not its output. The selection intensity that sets the size of the effect (beta = 6) is not declared anywhere in the text, and neither is the fact that P1 is the adapted parent. "The bulk is the worst scheme across the whole range" is presented as a finding. "Natural selection in the bulk removes precisely the germplasm the wide cross was made to introduce" is a mechanistic interpretation of a model that P6 itself declares phenomenological. The comparison with SSD at N = 30 depends on the undeclared beta.

- 04-D10 [criteria 7, 1, 5] qmd:41-43, and the roxygen at R/06_f2size.R:26-27 -- "IBM-type map lengths ... inflated 5-10x by construction" is uncited and is contradicted by the primary source: Lee et al. NON-DISQUALIFYING OBSERVATIONS

- 04-M1 qmd:385-387 -- "D and GD move together: the same loss in two coordinate systems" understates an exact identity. With 0/0.5/1 coding and theta = mean(f) including the diagonal, GD = mean(2pq) = D/2. The bridge table shows GD - D/2 = 0 to 1e-16. The relationship is described rather than stated (04-R10).
- 04-M2 qmd:395-397 -- "N_s returns approximately 1" is asserted in prose and not computed in the chapter. It follows from M1 as Ns = 1/(2 - D), which gives 0.966, 0.980 and 0.990 on the bridge panels (04-R11).
- 04-M3 qmd:41, :104 -- "1670 cM (~17 Morgans)" and "1.75 L" are hand-typed. Both are correct (04-R12).
- 04-M4 qmd:132, :148, :244, :371 -- one `set.seed()` covers several draws, so later panels depend on the stream earlier panels consume (04-R13).
- 04-M5 qmd:376 -- `run_scheme("SSD", ...)` runs SSD only because every name that matches no scheme falls through to the SSD branch. R/06_f2size.R:353 has no `match.arg` (04-R14).
- 04-M6 qmd:226, :242 vs :372 -- `s40` holds SSD at N = 30, and `map4` is rebound from a 4 cM map to a 10 cM map. The same symbol means two different things in one chapter (04-R15).
- 04-M7 qmd:320-327 -- "F ~ 0.95" is mapped to h_res = 0.05 without declaring that F is meant as the proportion of loci, among those polymorphic between the parents, that are still heterozygous in a parent. That is not the inbreeding coefficient relative to a base population.
- 04-M8 qmd:348 -- "share 87.5% of the genome" is the coancestry of two plants from the same selfed F3 plant, (1 + F_F3)/2 = (1 + 0.75)/2. It is not the proportion of genome they share. Two concepts are conflated in a single phrase.
- 04-M9 book/scripts/regenerate.R:12 -- the header says the f2size target writes "nine figures". It writes none (:68) (04-R16).

Count of non-disqualifying observations: 9. This would independently reject (>= 3).

WHAT WAS VERIFIED

- D = mean(2pq)/0.5 (R/06:416), with E[D] = 1 - (1 - H)/N -- verified algebraically: per-line dosage in {0, 0.5, 1} with probabilities ((1-H)/2, H, (1-H)/2) gives Var = (1-H)/4. Lines are independent under SSD, so Var(p_hat) = (1-H)/(4N) and E[2pq]/0.5 = 1 - (1-H)/N. Correct. SE = 0.5 sqrt((1-H)/N) is correct, and 0.5/sqrt(N) is its H = 0 case.
- Junction recursion -> 1.75 L at F4, Syn adds 0.5 L per cycle -- verified algebraically, and it matches `expected_junctions()` (R/06:534-541).
- Junction bias at 2 cM -- two-state approximation 0.966 (-3.4%), consistent with the audit's -3.7% and the cached grid (SSD mean `junc` about 28.1 vs 29.2 expected) -> 04-D1.
- f1_sizing values -- 1.953 / 0.977 / 0.488 / 0.122 at n = 8 / 9 / 10 / 12; the threshold is 9 -> 04-D2, 04-D3.
- Cached SSD grid -- marginal D gains, D(390) = 0.98863, pmin plateau 0.22-0.24 from N = 70, `junc` flat 27.6-28.6 across N; multilocus k = 5 non-monotone and first >= 0.95 at N = 270; k = 8 / 10 at N = 390: 0.373 / 0.070.
- bulk_weights -- z is the P1 share and weights rise with z, so selection against the donor is built in; beta_bulk = 6 appears only in f2_opt -> 04-D7.
- GD = D/2 exact; Ns = 1/(2 theta) about 1 -- algebra from the Caballero & Toro f with 0/0.5/1 coding, and the audit's bridge values.
- Coancestry of F4 plants within a line = (1 + F_F3)/2 = 0.875 -- the number is correct; the wording is in 04-M8.
- Regenerability of f2_results.csv / f2_multilocus.csv -- taken from the audit (PASS), not redone.
